# Documents

## Overview

Documents are context files that provide background knowledge about the project. These do not affect the runtime of the Virtual Assistant and are used purely for documentation purposes. These are also used by Poly's Studio Assistant to provide a place for ongoing context. They are stored as Markdown files in the `context/` directory.

## File structure
These are read from the `context/` folder. Only `*.md` files are discovered.

```
<account>/<project>/
  context/
    CONTEXT.md
    FUNCTION_GUIDELINES.md
    SUCCESS_CRITERIA.md
```
